# CRUD Operations Using Firebase Realtime Database

A simple Rust application demonstrating **Create, Read, Update, and Delete (CRUD)** operations using Firebase Realtime Database. The project uses asynchronous programming with Tokio and JSON serialization/deserialization with Serde.

## Features

- **Create:** Add a user record with a Firebase-generated unique key.
- **Read One:** Retrieve a user using their Firebase key.
- **Read All:** Fetch all user records into a Rust `HashMap`.
- **Update:** Modify an existing user's information, such as their email address.
- **Delete:** Remove a user record from the database.
- **Asynchronous Requests:** Use Tokio for asynchronous execution.
- **JSON Serialization:** Use Serde to serialize and deserialize user data.

## Technologies Used

- **Language:** Rust
- **Database:** Firebase Realtime Database
- **Firebase Client:** `firebase-rs`
- **Serialization:** Serde and `serde_json`
- **Asynchronous Runtime:** Tokio

## Data Model

Each user is represented by a Rust struct:

```rust
#[derive(Serialize, Deserialize, Debug)]
struct User {
    name: String,
    age: u32,
    email: String,
}
```

Firebase stores user records under the `users` node, with a unique key identifying each record.

Example database structure:

```json
{
  "users": {
    "-P4yj7xDv6d1_56Pytcr": {
      "name": "Arjun Mukherjee",
      "age": 20,
      "email": "arjun@example.com"
    }
  }
}
```

The key shown above is an example generated by Firebase.

## Setup and Installation

### 1. Install Rust

Install Rust and Cargo using [rustup](https://rustup.rs/) if they are not already installed.

Verify the installation:

```bash
rustc --version
cargo --version
```

### 2. Clone the Repository

```bash
git clone https://github.com/dewdropx/crud-firebase.git
cd crud-firebase
```

### 3. Configure Firebase

1. Create a project in the [Firebase Console](https://console.firebase.google.com/).
2. Create a Realtime Database.
3. Copy the database URL.
4. Configure appropriate database security rules for your application.
5. Update the database URL in `src/main.rs`.

### 4. Install Dependencies

Cargo downloads the required dependencies automatically when you run the project.
Ensure your `Cargo.toml` includes the dependencies used by your implementation, such as `firebase-rs`, `serde`, `serde_json`, and `tokio`.

### 5. Run the Project

```bash
cargo run
```

To check whether the project compiles without executing it:

```bash
cargo check
```
